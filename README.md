# ✳ Atlas of Interesting Things

Things I find interesting, concepts I would like to expand from courses that I've taken in ANU. The idea is create different exhibits / labs to play around with the concepts that I've learned, and use this process to understand `TypeScript`, `Three.js`, and `Rete.js`. (Web dev is not my forte). 

## Start playing

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Visit the local URL shown in your terminal. Production build:

```bash
npm run build
```
